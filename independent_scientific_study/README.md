# Independent Scientific Study – Insect Detection

This repository collects research papers and summaries for an independent scientific study conducted prior to the master's thesis by Atul Santhosh (MSc Computer Science)  
The study focuses on **Insect Detection**, emphasizing object detection algorithms, domain-specific datasets, and methodological approaches.

## Repository Structure

| Folder | Description |
